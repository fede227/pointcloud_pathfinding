# PointCloud Pathfinding with Python
This Python script is a tool that I developed to validate my work on LiDAR-based SLAM to use the 3-dimensional map generated by the SLAM algorithm to calculate obstacle free trajectories using the A* algorithm. 
Dependencies
The script uses the open3d, 
The way the script works is by projecting a slice of the 3D map, perpendicular to the z-axis, on a 2D image. To achieve this the script requires the z-min and the z-max values to select the points that will be part of the image. The idea behind these coordinates is to allow the user to make a rough estimate of the altitude that the vehicle will have while following the calculated trajectory. 
In the images underneath you can see the results of the image projection. 


After having projected the entire map the A* algorithm is used to estimate an obstacle free trajectory between the desired starting and ending points of the map, provided they are reachable and are not occupied by obstacles. At this stage a weighted map is used to avoid trajectories that run too close to the obstacles. This operation can be customized with the margin and penalty launch parameters, which allow the user to select the number of pixels around an obstacle which are considered impassable and the weight that will be attributed to the pixels near the obstacle respectively (3 and 5 are the default values). Furthermore it is possible with the diagonal launch parameter to disable or enable diagonal movement on the map (default is allowed).
